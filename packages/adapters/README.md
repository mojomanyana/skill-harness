# @skill-harness/adapters

Harness adapters for [skill-harness](https://github.com/mojomanyana/skill-harness):
the Pi subject/judge runner, the frozen pi-daddy 0.17/v2
normalizer, and the separately pinned production ledger-v3 normalizer.

Run `skill-harness --help` to see the exact Pi releases qualified by your installed
Harness. Judges require a listed release. See [Pi qualification](https://github.com/mojomanyana/skill-harness#pi-qualification)
for compatible subject versions, strict mode and how the Harness records the version used.

Internal — use the `skill-harness` CLI. See the repo for docs.

ESM, Node ≥ 20.
