# Two-domain local evidence replay — P16 fixture slice

This runs actual implemented APIs with fixed synthetic software/layout worlds. It is NOT a live daily case, a model experiment, authenticated human review, a bounded P15 order or full-factory qualification.

After a direct compiler build, choose a NEW explicitly owned output directory:

```sh
node examples/factory-local-replay/replay.mjs --output /absolute/owned/new-replay
```

The output must not exist; parent must exist. The replay leaves its synthetic archive/spec/summary evidence for inspection. It never installs, contacts a model, dispatches a worker, edits a source skill, or publishes anything. Do not point it at historical evidence.

Measured fixture path:

1. Actual pinned P01 builders produce two obligations, three exact attempts and fixed acceptance/rejection claims. Independent fixture authority is reconstructed from a fixed expected world, never from incoming wire. Session/branch labels are **test-world declarations**, not native authentication.
2. Exact work bytes are archived and projected by the pinned pure producer reader. One obligation is accepted under supplied fixture authority; one remains unaccepted.
3. Structural rules nominate repeated work and an economical accepted example without a manual note. Input snapshots and cases are retained. A fixture operator records a case decision in the real selected-batch store.
4. An identity-bound hypothesis gets a separate exact scenario-preview authorization. The existing spec writer appends once and recognizes exact replay. Evaluation inputs freeze with executionReady:false.
5. Fixed synthetic role/evidence context and real retained output bytes exercise the separate comparison/quality-before-cost API. A cheaper failed arm is ineligible; no routing default is produced.
6. Adoption predicates bind a fixture choice to future-order scope, with grantExpansion:false. No activation is applied. Later outcome remains unknown.

The first actual integration attempt correctly refused acceptance with unknown branch labels; that diagnostic is preserved in local evidence. Explicit synthetic labels repaired the fixture, not production guarantees. It also exposed a real detector distinction: TRUSTED_REJECTION is not missing evidence. That narrow correction ships as detector implementation structural-work-v2; old versions/cases remain historical rather than silently inheriting trust.
