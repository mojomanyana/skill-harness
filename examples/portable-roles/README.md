# Portable role acceptance examples

Prepared through skill-harness authoring, not advertised as model-qualified. Skills use Pi alone. Wrappers are optional read-only pi-daddy definitions; no Principal dependency. Evaluations are separate under evals/. All facts are synthetic and provided in the prompt; no hidden fixtures or external accounts. Calibrations remain proposed until the operator accepts exact labels. No provider calls, deployment or training authorization is inferred.

The example package is private and is not installed by preparing it. Copy a skill directory into another Pi role package without copying these evals or wrappers. Domain connector rollout remains separate.

The `connectors/` example tests a named Calendar provider's documented lost-response
and version-conflict boundaries using synthetic local data. It has no account access
or production adapter. See its README for the contract sources and limitations.
