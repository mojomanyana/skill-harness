# Draft: approving an investigation is not adopting a change

The archive can now issue a bounded read-only capability, and proposed investigations carry frozen evidence, alternatives, predictions, disproof and limits. Scenario promotion requires separate exact preview/target consent and uses the existing append-only spec writer.

Rubric, judge, held-out or configuration drift invalidates the evaluation freeze. Weekly selection is idempotent. None of this runs a model, expands authority or adopts a candidate; live host/route qualification and the execution charter remain separate requirements.
