# Draft: a weekly retro needs more than a read-only prompt

A closed reader and a hypothesis function are not a weekly investigation lifecycle. The missing pieces are ownership, retained decisions, effect claims and a real denied-operation boundary.

The new archive path uses a finite **data-only inert host**. It reads only approved archived manifests, requires current confirmed case decisions, persists one weekly claim and proposal, and has no instruction for shell, arbitrary filesystem/network, session or grant mutation. A live model host remains separately unqualified; this is not a claim that injected JavaScript is sandboxed.

Promotion calls the existing exact-preview/spec writer. Evaluation files are frozen from actual bytes before a separately approved candidate edit. Reopening does not reset ownership, recover a torn journal or silently rerun an ambiguous effect.

Trust now has an equally concrete history: predeclared policy and unflagged sample, immutable predictions and corrections, independent retained outcomes, and durable attention reservations. The real case reviewer can supply a linked outcome; withdrawing that confirmation removes it from current confidence without rewriting history. Eight correct, two incorrect and three unresolved stays **8/10 plus3 unresolved**. A different directory cannot refill the same policy's attention.

These are connected offline paths, not live efficacy, authenticated human consent or a new routing default. The original whole-change CHANGES-REQUESTED verdict remains preserved while repairs are validated.
