# Draft: real ports, explicit limits

The replay now consumes Principal's generic lifecycle through the actual harness archive: exact output bytes, origin-bound receipts, and retained source pins. Legacy unbound retirement stays unchanged; the new lifecycle separately emits the retirement it can prove.

The real dashboard loader and host reuse the replay's existing stores. Fixed-order failures feed scoped facts, while missing presence stays missing. No replacement authority or attention budget is created.

Reviewed export now has actual redaction, exact preview permission, byte readback and an expiring access lease. That lease does not erase old files or revoke every archive API. Credential-pattern screening is not exhaustive privacy assurance, and fixture permissions are not authenticated consent.

These are connected implementations with explicit limits—not a new overall approval or live qualification.
