# Draft: native retention is not acceptance

The external archive now consumes a pinned pi-daddy retention contract, with exact schema/fixture parity and the producer's strict validator. Session and receipt references become available only when their actual bytes match. Missing and corrupt bytes remain visible on reread.

Execution IDs—not reused child names or timestamps—drive joins. Contradictory outcomes and cyclic parentage stay explicit. A reported live branch remains reported, not independently authenticated active state. The read model cannot carry acceptance or activation authority.

The downstream schema/fixture supports read-only daily views. Live qualification, deployment policy and behavioral acceptance remain separate work.
