# Draft: an archive command without a hidden observer

The new offline archive command ingests one operator-allowlisted file under an explicit private policy, then prints metadata rather than raw payloads. Inspection is read-only. Expired policies, symlinks, traversal, extra options and oversized inputs fail before becoming archive evidence.

Partial or missing content remains partial or missing even when storage itself succeeds. Policy selection is not an authenticated approval, automatic redaction or OS containment. Producer semantic integration and live qualification remain separate work.
