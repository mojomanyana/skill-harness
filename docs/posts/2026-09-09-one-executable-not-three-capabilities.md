# One executable, not three disconnected capabilities

A producer adapter, a five-role API and a process monitor are not yet a selected invocation.
The local caller now joins them: one pinned worker, one original producer graph/budget,
one bounded release frame, empty environment and independent parent supervision.

The same worker exercises all five roles in an inert split-panel proof. Fixture mode cannot
select live ports or accept live approval. Live preparation names the actual missing facts:
canonical/account provenance and separately approved execution—not another helper.

That closes a caller-composition gap, not all campaign acceptance. A five-call integer
fixture is neither an N2/N3 skill-variant experiment, judge calibration nor later production
outcomes. Those need their own exact work and observations; a repair percentage hides them.
