# Five reservations can mean four calls

A producer-backed qualification path must not invent a second lifetime owner. The new
explicit five-role entry uses the existing producer owner, reserves the whole batch once,
and feeds original child stdout through the existing host journal and SDK seam.

Four calls ordinarily suffice; the fifth judge is reserved for the existing split rule.
Unused original permits are cancelled, not refunded. A queued slot is an active hold,
not a concurrent HTTP request. Failed and stranded attempts remain counted.

Completion is not a returned response. Every next role waits for original acknowledged
settlement. A bounded timeout may stop the observer, but it cannot release unknown
ownership. Even visible settlement bytes are insufficient when the required sync failed.

The standalone host-frame entry stays explicit. Actual-child, installed-SDK tests use
inert HTTP and no credentials or network; they do not provide canonical account identity,
hard host resource guarantees, live provider qualification or native acceptance.
