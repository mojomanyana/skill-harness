# Draft: An IPC reference is not settlement

The opt-in producer adapter connects a single reserved invocation to its frozen host charter. Only bytes captured from the original child pipe reach the SDK validator; no credential, endpoint or arbitrary model payload reaches that child.

The host returns actual journal claim/response references. They do not grant acceptance. A successful response stays ineligible while original producer settlement is pending, and judge emission remains blocked. Only matching completed ownership acknowledgement unlocks that source's artifact; failed, cancelled or unknown settlement does not become success.

Original bounded observation and original completion remain distinct handles. The cancellation signal reaches host I/O; an observer timeout cannot release a resource or retry a call. Connected tests use the real producer child and installed SDK with inert HTTP, not a live provider or backend attestation. Canonical/account/host/live qualification and native acceptance remain separate work.
