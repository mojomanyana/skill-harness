# The empty fact is not a guess

A retained work ledger already knows some things: which obligation was selected, which attempt IDs were observed, and whether artifact/evidence coverage is missing. It does not know that a timeout was unexpected, that a failure violated acceptance, or that silence means waiting.

The first automatic learning slice therefore derives less, not more. When no separate host-facts source is supplied, the archive adapter creates an observed-work fact set with no expected waits, deadlines, violations, or prior acceptance. Coverage candidates still come directly from the real projected obligation. Runtime failure does not become an objective defect, and absence does not become a deadline.

That is enough for a real retained task to produce a silent traceable case without `/note`. Richer checkpoint, reopen, and intent-conflict candidates still require their actual evidence sources.
