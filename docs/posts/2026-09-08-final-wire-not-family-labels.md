# Draft: Final wire evidence, not family labels

Canonical self-judging and correlated judges are different problems. The first must be refused before effects; shared family/lineage must be disclosed rather than mistaken for independent training—or a universal impossibility.

The local Codex host now connects its durable claims and objective-before-blind panel to the installed SDK serializer, compressed request bytes and response decoder. In a network-unshared fixture, malformed, reordered, truncated, replayed and tampered exchanges cannot become objective-passing output. Quota failures do not retry.

This is deliberately not a live result: the sole credential is invalid, fetch is inert, the accepted SSE profile is narrowly text-only, and no ordinary Pi extension rejection changes. Host-observed bytes are not backend attestation. The proposed hard server-token cap remains unsupported; that limits that charter, not subscription-only execution universally.
