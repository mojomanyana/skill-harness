# Draft: Host bytes are not backend facts

An extension can rewrite what a subject says it sent. Parsing its transcript in a parent process does not change who authored that evidence.

Our local boundary now puts frozen request construction, durable sequence claims and transport writes in the host. An actual credentialless namespace probe supplies only a bounded invocation frame. Objective-passing bytes become anonymous judge input; a tie-break is admitted only after a clean split. Failed writes remain counted after reopen.

That proves something useful—but only something precise. Host-written body bytes are not proof of provider receipt, backend model identity or accepted reasoning settings. A fixed Linux probe is not an arbitrary-model resource qualification. A consistent fixture role map is not independent model lineage. None of these tests makes a provider call.

The next gate stays closed: subscription-only Codex, exact bounded approval, independently justified identities and resources, and supported token-cap semantics. No API fallback, quota workaround or model judgment on the controller path. Local tests are evidence, not permission to spend or merge.
