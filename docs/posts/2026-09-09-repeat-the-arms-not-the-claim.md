# Repeat the arms, not the claim

A five-role arithmetic smoke test cannot establish arm variation, calibration or learning.
The opt-in product composition now freezes actual model/effort/skill/prompt bytes and a
finite repeated/heldout cell schedule. It reserves the entire experiment once through the
original producer, then measures the SDK-serialized requests and original settlements.

The archive retro uses the same selected worker but only the existing reader's bounded
selected bytes. Its result stays proposed. No new store, credential loader or model-driven
dispatch loop was needed.

The local N2/N3 proofs are explicitly serial replay with inert HTTP. Synthetic labels test
the wiring, not real judge accuracy. Backend facts, production stability and later outcomes
remain unknown until actual observations exist. Useful implementation progress is not an
acceptance percentage.
