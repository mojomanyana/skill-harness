# Draft — Loaded is not invoked

A package can be installed without its resources being discovered. An extension can
be loaded without participating in the model invocation you measure.

Our bounded installed-session review path connects the second gap: the original
producer reserves the pair; a fresh installed AgentSession runs each role; actual
before-agent/context/provider hooks precede the SDK call. The provider sees that
processed context, while a frozen transformation policy and final-wire comparison
keep resource drift, extra tools and accidental continuations from reaching it.

The subject's acknowledged final text is sealed before the independent judge task
is constructed. Neither a valid response nor an advisory grade authorizes adoption.

Offline proof uses the actual installed SDK and producer with inert responses,
including a real deadline and deliberately faulty context/wire/settlement ports.
It is evidence about the connection and its limits—not a live model result, human
calibration or control of somebody's existing terminal session.

Status: unpublished draft; no new measured call or acceptance claim.
