# Draft: learn from a completed session without rewriting its history

A passing task can still contain slow handoffs, repeated tools, missing review
context or user corrections. The new session retrospective keeps that evidence
together: select a Pi transcript and any known ledger, child transcripts, feedback
and artifacts; preview their hashes; explicitly retain exact local bytes.

The existing learning interface then shows chronological excerpts, individual
delegations, models and reported usage. Full sources remain available. A reviewer
can attach a finding or experiment proposal to an exact source line.

Missing child transcripts stay visible as gaps. An agent saying "done" is not
acceptance, and provider usage is not a bill. Nothing here silently edits skills,
starts models or activates a policy. Retention is local and exact, so inspect
sensitive source content before confirming.

This is the foundation for comparing later workflow changes with real evidence.
It is not yet an automatic optimizer or proof of improved quality or speed.

Publication status: draft accompanying the implementation; release evidence belongs
to the PR and release record.
