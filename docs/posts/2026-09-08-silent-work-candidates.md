# Draft: work evidence can nominate, not decide

A separate work-target capture model now links silent candidates to exact scope and obligation revisions. Repeated equivalent observed attempts can nominate lack of progress; missing coverage is a coverage issue, and an economical exemplar needs accepted work plus cited measured usage. Expected waits, expected failures and changed requirements are negative controls.

The actual input snapshot is retained before candidate records. Multiple observations of one incident do not become independent evidence. No note, model call, scored test, promotion, alert exposure or runtime authority is manufactured. Human/controller decisions remain a separate attributable correction chain.

Native archive CLI ingestion also now requires explicit policy-v2 consent before following pinned content references. Existing policy-v1 stays non-traversing.
