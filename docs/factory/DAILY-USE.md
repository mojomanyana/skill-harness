# Factory continuation — daily use (unreleased)

These commands describe the review branches, not released npm 0.13.0/0.23.0 behavior.

1. Declare one current obligation without editing JSON:
   `pi-daddy work add --id <fresh-id> --outcome "<outcome>"`.
2. Start/reload Pi with the matching pi-daddy extension. Ordinary governed delegation records starting and terminal attempts. Runtime completion is not acceptance.
3. Open `/grants dashboard`. The read-only view shows obligations and attached attempts. A connected production host is still missing; until it lands, do not claim that labelled action keys can steer a real busy child.
4. For independent variants use one bounded `delegate_all`, explicit `provider/model`, thinking and correlation `context_id` per child. Freeze the response count first. Sol/Terra low/high request selection has been observed; provider-internal reasoning is not asserted.
5. Retained work can nominate a silent coverage case without a note or facts file. Richer waits, checkpoints, objective failures and reopen facts require their actual evidence.
6. Use Principal's current human report from PR41 for current/stale/superseded status; `--format human-legacy` is the historical view.

Do not merge/publish these follow-ups from this guide. Human acceptance, blind quality choice, adoption and later outcomes remain explicit separate operations.
